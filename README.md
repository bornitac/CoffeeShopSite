# Bornita's Coffee Shop

A responsive coffee shop website with a product catalog and shopping cart.

**Live site:** https://bornita-coffee-shop.vercel.app

## Built With
- HTML5, CSS3, JavaScript
- Deployed on Vercel

## Features
- Product catalog with 6 items, prices, and images
- Add to cart, update quantities, and remove items
- Real-time cart totals via DOM manipulation
- Cart persists on refresh via localStorage
- Fully responsive across mobile, tablet, and desktop using CSS Grid

## Running Locally
Open `index.html` directly in your browser — no setup needed.
