# Bornita's Coffee Shop

A responsive coffee shop website with a product catalog and shopping cart built using HTML, CSS, and JavaScript.

---

## 🔍 What It Does

- Displays a product catalog of 6 coffee items with images and prices
- Allows users to add items to a shopping cart with a single click
- Updates cart totals and item counts in real time using DOM manipulation
- Supports quantity editing and item removal from the cart
- Persists cart data using localStorage so items remain after page refresh
- Fully responsive across mobile, tablet, and desktop using CSS Grid and Media Queries

---

## 🛠️ Built With

- **HTML5** – page structure and layout
- **CSS3** – styling, CSS Grid, and Media Queries for responsiveness
- **JavaScript** – DOM manipulation, cart logic, and localStorage

---

## 🚀 Getting Started

### Option 1 – Open directly in browser
Just open `index.html` in your browser — no setup needed.

### Option 2 – Run with local server
```bash
npm install
npm start
```
Then open `http://localhost:8080` in your browser.

## 📋 Features

- CSS Grid product layout that adapts to screen size
- Real-time cart updates without page reload
- Cart persists across page refreshes via localStorage
- Mobile-friendly cart that collapses to a single column on small screens
